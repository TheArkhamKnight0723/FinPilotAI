# FinPilot AI

## Overview
**FinPilot AI** is an intelligent financial navigation platform designed to deliver real-time financial insights, automated analytics, and personalized guidance powered by AI.

---

## Tech Stack
- **Frontend**: React, Node.js
- **Backend**: FastAPI (Python)
- **Database**: PostgreSQL
- **AI Integration**: Custom LLM agents & financial analysis tools
