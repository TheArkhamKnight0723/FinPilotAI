# Contributing to FinPilot AI

Thank you for contributing to **FinPilot AI**! Please follow these guidelines when submitting contributions.

## Development Workflow
1. **Branching Strategy**:
   - `main`: Production-ready baseline
   - `frontend`: React frontend development
   - `backend`: FastAPI backend development
   - `database`: PostgreSQL database schemas & migrations
   - `ai`: AI agent development & LLM integration
   - Feature branches: `feature/<feature-name>`

2. **Commit Messages**:
   - Use clear, descriptive commit messages.

3. **Pull Requests**:
   - Ensure code compiles and passes tests before opening a PR.
   - Reference associated issues in your PR description.
